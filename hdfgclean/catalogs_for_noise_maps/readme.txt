This directory contains catalogs of point sources (CIB+radio) and tSZ clusters for the maps used to quantify the noise in the matched filter calculation, as described in the "Before using `HDFGClean`" section of the `hdfgclean` github repository readme file. We will refer to these as "noise maps" below.

Note: it is very unlikely that you will ever need these files. If you are looking for, e.g., catalogs output by running the FG cleaning procedure described in MacInnis et. al. (2026), then you are in the wrong place: you will need to reproduce them yourself by following the instructions in `reproduce_10x10.ipynb`, located in the `reproduce_10x10/` directory of the `hdfgclean` github repository. 

The `ra26dec6_3x3deg_apod0.25deg` directory contains catalogs used for the default set of noise maps used in `hdfgclean`; these are 9-square-degree maps generated by `hdsims`, centered at R.A. = 26 degrees and dec. = 6 degrees, and are apodized using a 0.25 degree apodization width. The `ra26dec6_2x2deg_apod0.2deg` directory contains catalogs for an alternative, smaller four-square-degree patch at the same location, with a smaller apodization width of 0.2 degrees. The catalogs in each directory were produced by running the default FG cleaning procedure (but with a different set of "noise maps") on the corresponding patch; the catalogs contain the point sources and clusters that were subtracted by the FG cleaning.

To understand how these catalogs are used, consider FG cleaning maps that have CMB + kSZ + tSZ + CIB + radio + instrumental noise:

  - The first step is filtering the maps to find CIB + radio point sources. In this case, the "noise maps" (as opposed to the CIB+radio signal we are looking for) are maps of the CMB + kSZ + tSZ + instrumental noise.
  
  - After subtracting sources, the maps contain CMB + kSZ + tSZ + residual CIB + residual radio + instrumental noise. When we filter these maps to find the tSZ, the "noise maps" are now CMB + kSZ + residual CIB + residual radio + instrumental noise (i.e., everything but the tSZ). To make these noise maps, we start with maps that contain CMB + kSZ + all CIB + all radio + instrumental noise, and subtract the point sources from the catalogs provided here to get the residual CIB and radio.
  
  - After FG cleaning, we have maps of CMB + kSZ + residual tSZ + residual CIB + residual radio + instrumental noise. We again filter the maps to find any remaining point sources (e.g., they may have originally been hidden "below" a cluster which has now been removed), so now the "noise maps" contain CMB + kSZ + residual tSZ + instrumental noise; the cluster catalogs provided here are used to get the residual tSZ part of the maps.
