# Examples

We provide two examples here:
- `hdfgclean_example_2x2.ipynb`: example using the `HDFGClean` class with `hdsims`
- `fgclean_example_2x2.ipynb`: example using the more general `FGClean`, designed for any set of maps compatible with `pixell`


Although the `FGClean` class can be used with a more general set of maps, we use the same set of four-square-degree maps in both examples. The maps have been generated by `hdsims`; we will tell you how to download them, so you do not need to generate them yourself. In `fgclean_example_2x2.ipynb`, we only use `hdsims` to save the maps that are passed to `FGClean`. Both examples provide complete instructions to run the FG cleaning on these maps.
